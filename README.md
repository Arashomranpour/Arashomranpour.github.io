## ✨ About

A hand-written, dependency-free portfolio served by **GitHub Pages**:

- ⚡ Single `index.html` with embedded styles and scripts - no build step.
- 🎨 Custom design using the *Montserrat* and *Inter* fonts and **Font Awesome** icons.
- 📱 Responsive layout for desktop, tablet and phone.

## 🚀 Run locally

```bash
git clone https://github.com/Arashomranpour/Arashomranpour.github.io.git
cd Arashomranpour.github.io
python -m http.server 8000      # then open http://localhost:8000
```

Any push to the default branch is published automatically at **https://arashomranpour.github.io**.
